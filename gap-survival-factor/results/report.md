# `fill3_direction` 测试结果汇报

## 历史滚动回测

- 数据：动态沪深300历史日线，859只股票，2007-01-04至2024-10-30。
- 验证期：2019-01-01至2021-12-31。
- 历史复验期：2022-01-01至2024-10-30；该区间已被研究过，不称为完全未见样本外。
- 训练：过去504个交易日滚动训练，月初更新，训练事件至少提前3日成熟。
- 交易：T日信号、T+1开盘买入、持有5个交易日，只做多，Top20%，事件池少于50只不新开仓。
- 成本：买入和卖出各单边万分之一；另有4.8%成交阻断代理，不包含真实滑点和容量。

2022-2024复验：RankIC 0.0129，95%区间[-0.71%,3.29%]；净CAGR 3.78%，同池基准CAGR -0.72%；年化日均超额4.82%，95%区间[-6.25%,15.91%]。2019-2021年化超额为-2.63%。

## 复现文件

- `gap_survival.py`：特征和事件核心函数。
- `factor.py`：调用冻结模型生成唯一因子分数。
- `frozen_model.npz`：冻结模型参数。
- `run_report.py`：打印保存的结果摘要。
- `test_factor.py`：事件阈值、矩阵形状和基础逻辑测试。

当前结果支持教学和研究复现，不支持宣称该因子具有稳定可交易Alpha。
