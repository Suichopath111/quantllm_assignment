# 跳空寿命方向因子（`fill3_direction`）

## 1. 因子定义

对股票在交易日 `T` 的开盘跳空定义：

```text
gap_T = open_T / close_(T-1) - 1
```

只保留 `abs(gap_T) >= 0.1%` 且在 `T` 收盘时尚未回补的事件。

- 正跳空：未来价格最低价 `low <= close_(T-1)` 时视为回补。
- 负跳空：未来价格最高价 `high >= close_(T-1)` 时视为回补。
- 未来3个交易日内没有回补，记为右删失，不当作“未回补”的确定标签。

使用离散时间 Logistic 风险模型估计 `P(fill within 3 days)`。输入包括跳空方向、波动率归一化跳空距离、日内变化、振幅、方向化CLV、前期波动率和股票池市场平均收益，并加入1/2/3日期限哑变量。

本项目唯一使用的交易分数为：

```text
fill3_direction = sign(gap) * (1 - 2 * P(fill within 3 days))
```

分数为正时表示继续沿跳空方向交易，分数为负时表示反向交易。这里的 `3日`是预测期限，历史账户仍采用5日持仓。

## 2. 数据与研究范围

使用本机 `lab/csi300/daily/*.parquet` 和历史沪深300成分数据：

- 859只股票，动态成分股票池；
- 日线开、高、低、收数据；
- 数据覆盖2007-01-04至2024-10-30；
- 事件样本由历史成分和可用价格共同决定。

复权、停牌、涨跌停和公司行动信息并不完整，结果是研究回测，不是实际成交承诺。

## 3. 训练、验证和测试划分

- 模型窗口：过去504个交易日；
- 每月月初重新拟合；
- 训练事件必须在拟合日前至少完成3日成熟期；
- 训练特征按训练样本1%/99%缩尾后标准化；
- 验证期：2019-01-01至2021-12-31；
- 最终历史复验期：2022-01-01至2024-10-30。

最终历史复验已经被研究过，因此不能称为完全未见样本外。

## 4. 历史因子研究表现

概率模型本身能够识别回补风险，但这不等于交易收益稳定。最终历史阶段的单因子账户结果如下：

| 指标 | 2022-2024-10-30 |
|---|---:|
| RankIC | 0.0129 |
| RankIC HAC t值 | 1.26 |
| RankIC 95%区间 | [-0.71%, 3.29%] |
| 策略净CAGR | 3.78% |
| 同规则基准CAGR | -0.72% |
| 年化日均超额 | 4.82% |
| 超额HAC t值 | 0.85 |
| 超额95%区间 | [-6.25%, 15.91%] |
| 最大回撤 | -25.09% |

验证期2019-2021的5日账户年化超额为 `-2.63%`，因此前后时期并不稳定。

概率模型的回补识别指标：

| 阶段 | 1日AUC | 2日AUC | 3日AUC |
|---|---:|---:|---:|
| 验证期 | 0.793 | 0.758 | 0.740 |
| 最终历史复验期 | 0.791 | 0.756 | 0.737 |

## 5. 交易规则和成本

- `T`日收盘生成分数；
- `T+1`开盘买入；
- 最早持有5个交易日后，在开盘尝试卖出；
- 只做多，选分数最高的前20%；
- 单边交易成本：万分之一；买入和卖出均收费；
- 同池等权组合作为基准；
- 事件池少于50只股票时不新增仓位；
- 4.8%涨跌幅限制只是成交阻断代理，不是真实涨跌停撮合；
- 未加入真实滑点、冲击成本、印花税、最低佣金和容量限制。

## 6. 项目文件

- `factor.py`：只实现 `fill3_direction` 的特征、回补标签和分数计算。
- `frozen_model.npz`：2008-2014固定训练模型参数。
- `results/`：历史研究与20只股票样本外结果摘要。

结论：该因子可以作为研究和教学示例，但现有数据下没有足够证据将其视为稳定可交易Alpha。
